# เหนื่อยใจ Pass Shop

เว็บขายพาสและไอเทมของแมพเหนื่อยใจ สมัครสมาชิก เติมแต้ม ซื้อของด้วยแต้ม แล้วได้โค้ดไปกรอกในเกม

- **ขายอะไร**: พาส (มีได้ชิ้นเดียวต่อคน) และไอเทมที่ซื้อซ้ำได้ ได้แก่ กล่องเลือก คริสตัลผนึก บัตรต่างๆ และตั๋วสุ่มกาชา
- **ราคา**: ราคาบาท = ปัดขึ้น(ราคา Robux เต็มของทั้งตะกร้า ÷ 6) อัตรานี้แก้ได้ในหลังบ้าน
- **เติมแต้ม**: 1 บาท = 1 แต้ม เติมได้ 2 ทาง แอดมินเปิด/ปิดแต่ละทางได้ในหน้าตั้งค่า
  - ซองอั่งเปา TrueMoney: ระบบรับซองแล้วแต้มเข้าทันที
  - พร้อมเพย์: สแกน QR ที่มียอดเงินในตัว โอน แล้วแนบสลิป แอดมินตรวจแล้วกดอนุมัติที่ `/admin/slips` มีปุ่มทักแอดมินทาง Discord ให้ผู้ใช้กดได้
- **แอดมินจัดการแต้ม**: เติม คืน หรือหักแต้มให้ผู้ใช้ได้ที่หน้าผู้ใช้ในหลังบ้าน
- **โค้ด**: ในตะกร้าเลือกได้ว่าจะรวมทุกชิ้นเป็นโค้ดเดียว หรือแยกโค้ดทีละชิ้น ไอเทมที่ซื้อหลายชิ้นรวมในโค้ดเดียวได้
  - โค้ดยาว 12 ตัว (`XXXX-XXXX-XXXX`) ใช้ได้ครั้งเดียว ไม่ผูกกับไอดี
  - ถ้าผู้เล่นมีพาสในโค้ดอยู่แล้ว เกมจะไม่รับโค้ด และโค้ดยังไม่ถูกใช้

เทคโนโลยี: Next.js 15, Neon (Postgres), Drizzle, Tailwind 4 ขึ้นบน Vercel

## รันในเครื่อง

```bash
npm install
npm run dev
```

ถ้า `DATABASE_URL` เป็น `pglite:<โฟลเดอร์>` หรือว่างอยู่ จะใช้ฐานข้อมูลในเครื่องและสร้างตารางให้อัตโนมัติ
ส่วน `TRUEMONEY_MOCK=1` คือโหมดทดสอบ ใช้ซองชื่อ `TEST100xxxxxx` แทนซองจริงได้ (100 บาท) โหมดนี้ปิดเองตอนขึ้นจริง

## ขึ้นใช้งานจริง

1. **Neon**: สร้างโปรเจกต์ (region Singapore) แล้วคัดลอก connection string แบบ *pooled*
2. **สร้างหรืออัปเดตตาราง**: ใส่ connection string ใน `.env.local` ที่ `DATABASE_URL=...` แล้วรัน `npm run db:migrate`
   ทุกครั้งที่มีไฟล์ใหม่ในโฟลเดอร์ `drizzle/` ต้องรันคำสั่งนี้ก่อน deploy
3. **Vercel**: import repo นี้ แล้วใส่ Environment Variables:
   | ชื่อ | ค่า |
   |---|---|
   | `DATABASE_URL` | connection string ของ Neon |
   | `TRUEMONEY_PHONE` | เบอร์ TrueMoney ที่รับเงิน |
   | `PROMPTPAY_ID` | (ไม่บังคับ) เบอร์หรือเลขบัตรพร้อมเพย์ ถ้าไม่ใส่จะใช้เบอร์เดียวกับวอลเล็ต |
   | `ADMIN_USERNAMES` | ชื่อผู้ใช้ที่เป็นแอดมิน (คั่นด้วย `,`) |
   | `GAME_API_KEY` | รหัสลับยาวๆ ต้องตรงกับ Secret ในเกม |
   | `TRUEMONEY_API_BASE` | (ไม่บังคับ) พร็อกซีในไทย ถ้า TrueMoney บล็อกเซิร์ฟเวอร์ต่างประเทศ |
   | `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | กุญแจ Web Push สร้างด้วย `npx web-push generate-vapid-keys` ถ้าไม่ใส่ แจ้งเตือนเด้งบนเครื่องจะไม่ทำงาน แต่กระดิ่งในเว็บยังใช้ได้ |
   | `VAPID_SUBJECT` | URL ของเว็บ เช่น `https://nuaijaimarket.vercel.app` |
4. สมัครสมาชิกบนเว็บด้วยชื่อที่ใส่ไว้ใน `ADMIN_USERNAMES` แล้วจะเข้าหลังบ้านที่ `/admin` ได้

## ต่อกับเกม

สคริปต์ `ServerScriptService.Persistence.CodeRelay` ในเกม เรียก `POST /api/game/redeem` บนเว็บ
แต่ละรายการในโค้ดคือ id ในเกม แบ่งเป็น 3 แบบ:
- **พาส** (`Config.Passes.List`): เกมให้ผ่าน `PassService.grant`
- **กล่องหรือบัตร** (`Config.Passes.Boxes`): ได้ไอเทมนั้น 1 ชิ้น
- **แพ็กกาชา** (`gacha_xN`): ได้ตั๋ว `ticket_gacha` N ใบ

1. ใน CodeRelay ตั้ง `R.URL = "https://<โดเมนเว็บ>/api/game/redeem"`
2. Creator Dashboard → เกม → **ข้อมูลที่ละเอียดอ่อน (Secrets)**: เพิ่ม `nh_code_key` ใส่ค่าเดียวกับ `GAME_API_KEY` และใส่โดเมนเว็บ
   ถ้าจะทดสอบใน Studio ให้ใส่ใน Game Settings → Security → Secrets ด้วย
3. Game Settings → Security → เปิด **Allow HTTP Requests**
4. File → Publish

## แอป (PWA) และการแจ้งเตือน

- **ติดตั้งแอป:** ติดตั้งลงหน้าจอโฮมได้
  - Android/คอม: กดปุ่ม "ติดตั้งแอป" บนเว็บ
  - iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
- **ไอคอน:** สร้างใหม่ได้ด้วย `node scripts/make-icons.mjs <รูป>`
  - ไอคอนแอปใช้รูปปกแมพ
  - ไอคอนบนแท็บเบราว์เซอร์วาดเป็นใบไม้ เพราะรูปปกย่อเหลือ 16px แล้วดูไม่ออก
- **กระดิ่ง 🔔:** เก็บแจ้งเตือนทั้งหมดไว้ในเว็บ เครื่องที่กด "เปิดแจ้งเตือนบนเครื่องนี้" จะได้แจ้งเตือนเด้งขึ้นมาด้วย (iPhone ต้องติดตั้งแอปก่อน)
- **ใครได้รับอะไร:**
  - แอดมิน (เช็คสิทธิ์ ณ ตอนส่ง): สลิปใหม่ ซองอั่งเปาเข้า ขายได้
  - ผู้เล่น (เฉพาะเจ้าของไอดี): สลิปอนุมัติหรือไม่ผ่าน แอดมินเติม/คืน/หักแต้ม คืนแต้มโค้ด
- **เครื่องที่ใช้ร่วมกัน:** แต่ละเครื่องรับแจ้งเตือนเฉพาะบัญชีที่ล็อกอินอยู่บนเครื่องนั้น ออกจากระบบแล้วเครื่องนั้นหยุดรับทันที

## รายการเทสของแอดมิน

- **ตีตราเทส:** ทุกอย่างที่บัญชีแอดมินซื้อ เติมซอง หรือส่งสลิป ถูกตีตรา `is_test` ตั้งแต่ตอนทำรายการ
- **ไม่นับรายได้:** ไม่นับในหน้าภาพรวม ไม่ขึ้นในหน้ารายการปกติ และไม่ส่งแจ้งเตือน "ขายได้"
- **ดูแยก:** ดูได้ที่ `/admin/tests`
- **ข้อยกเว้น:** สลิปเทสยังขึ้นในหน้าตรวจสลิปพร้อมป้าย "เทส" เพราะต้องกดอนุมัติได้
- **เปลี่ยนสิทธิ์ภายหลัง:** ไม่กระทบรายการเก่า ตราเทสยึดตามสิทธิ์ ณ ตอนทำรายการ

## สถานะโค้ด

- **ชื่อคนใช้:** เกมส่ง Roblox username, ชื่อที่แสดง และไอดีของคนใช้โค้ดมาด้วย ถ้าไม่ได้ส่งชื่อ เว็บจะดึงชื่อจาก Roblox ด้วยไอดีเอง
- **คนซื้อเห็น:** หน้า "โค้ดของฉัน" แสดงว่าใครใช้โค้ด และคนซื้อได้แจ้งเตือนเมื่อโค้ดของตัวเองถูกใช้
- **แอดมิน:** ค้นโค้ดด้วย username ได้ที่หน้า คำสั่งซื้อ / โค้ด

## คูปอง (`/admin/coupons`)

- **แต้มฟรี:** ผู้ใช้กรอกที่หน้าเติมแต้ม แต้มเข้าทันที
- **ส่วนลด:** ผู้ใช้กรอกในตะกร้า ลดเป็น % หรือเป็นบาท และตั้งยอดขั้นต่ำได้
- **วิธีสร้าง:**
  - สุ่มโค้ดได้ทีละไม่เกิน 500 ใบ ใส่คำขึ้นต้นได้
  - หรือตั้งชื่อโค้ดเอง แล้วกำหนดจำนวนคนที่ใช้ได้
  - ตั้งวันหมดอายุได้ และคัดลอกโค้ดทั้งชุดไปแจกได้
- **ข้อจำกัดการใช้:** คนหนึ่งใช้คูปองเดียวกันได้ครั้งเดียว และคูปองเดียวกันใช้ซ้ำจาก IP เดิมไม่ได้

## กันโกง

- **ราคาและแต้ม:** คิดที่เซิร์ฟเวอร์ทั้งหมด ตัดแต้มและนับสิทธิ์คูปองใน transaction เดียวกัน แต้มไม่ติดลบ และคูปองไม่เกินจำนวน
- **ซองและสลิป:**
  - ซองอั่งเปาเติมซ้ำไม่ได้
  - สลิปต้องให้แอดมินอนุมัติ และรูปซ้ำส่งไม่ได้
- **โค้ดเกม:** สุ่ม 12 ตัว ใช้ได้ครั้งเดียว และเกมคุยกับเว็บด้วยรหัสลับ
- **รหัสผ่าน:** ผิด 5 ครั้งล็อกบัญชี 10 นาที แอดมินกด **ปลดล็อก** ได้ที่หน้าผู้ใช้ ถ้าบัญชีแอดมินเองโดนล็อก ให้รัน `npm run unlock -- <ชื่อผู้ใช้>` ในเครื่อง
- **ปั๊มบัญชี:** สมัครได้ไม่เกิน 3 บัญชีต่อ IP ต่อวัน ระบบเก็บเฉพาะ hash ของ IP ไม่เก็บ IP จริง
- **Security headers:** ตั้ง X-Frame-Options, nosniff, Referrer-Policy และ Permissions-Policy ไว้แล้ว

## หมายเหตุ

- การรับซองอั่งเปาใช้ API ที่ไม่เป็นทางการของ TrueMoney ถ้าเขาเปลี่ยนระบบ ต้องแก้ไฟล์ `src/lib/truemoney.ts`
- ถ้าซองล้มเหลวแต่เงินเข้าแอปจริง แอดมินกด "เติมให้" ได้ที่หน้า `/admin/topups`
- สลิปเก็บเป็นรูปย่อในฐานข้อมูล ถ้ารูปเดียวกันถูกส่งซ้ำ ระบบจะไม่รับ และหน้าตรวจสลิปจะขึ้นเตือน
- เพิ่มสินค้าใหม่ได้ที่หน้า `/admin/products` โดย "รหัสในเกม" ต้องตรงกับ `id` ใน `Config.Passes` และต้องเลือกประเภท พาส หรือ ไอเทม ให้ถูก
